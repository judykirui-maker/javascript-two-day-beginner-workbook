# JavaScript Two-Day Beginner Workbook

## Project Overview

This repository contains my work for the JavaScript Two-Day Beginner Workbook. The project focuses on learning JavaScript fundamentals through practical exercises and building a Student Grade Management System.

The aim was to understand how JavaScript works, practise problem-solving and apply programming concepts to a practical project.

## What I Built

### Day 1: JavaScript Fundamentals

Practised:
- Variables and data types.
- Operators and calculations.
- Conditional statements.
- Basic functions.
- Working with JavaScript code and testing results.

### Day 2: Student Grade Management System

Developed a JavaScript program that:
- Stores multiple student records.
- Adds new students to an array.
- Calculates students' average marks.
- Assigns grades from A to F.
- Determines pass or fail.
- Displays student results.
- Searches for students by name.
- Identifies the top-performing student.
- Validates marks to reject negative values and marks above 100.
- Handles students with equal highest averages and an empty student list.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the JavaScript files using Node.js.

For Day 1:

```bash
node day1/index.js
```

For Day 2:

```bash
node day2/index.js
```

The results will appear in the terminal.
